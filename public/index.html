DEVELOPER QUICKSTART

Seamless Drop-In for Existing Clients

Configure in under two minutes with standard MCP clients and frameworks.

Add the proxy wrapper to your claude_desktop_config.json:

{
  "mcpServers": {
    "shielded-postgres": {
      "command": "npx",
      "args": [
        "-y", "mcp-shield", "wrap",
        "--target", "npx -y @modelcontextprotocol/server-postgres postgresql://user:pass@localhost:5432/db"
      ]
    }
  }
}

In Cursor Settings ➔ Features ➔ MCP Servers, configure:

Name: MCP-Shield-Gateway
Type: command
Command: npx mcp-shield proxy --port 8080 --key mcp_live_sec_your_key

Python SDK integration for LangChain and CrewAI agents:

from mcp_shield import ShieldClient

client = ShieldClient(
    gateway_url="https://mcp-shield-gateway-core.vercel.app/v1/mcp",
    api_key="mcp_live_sec_your_key"
)

# Executes safe query through the policy firewall
response = client.call_tool("postgres_read", {"query": "SELECT id, name FROM users LIMIT 100"})
print("Signature:", response.attestation_signature)

Standard TypeScript / Node.js integration:

import { McpShieldClient } from '@mcp-shield/sdk';

const shield = new McpShieldClient({
  gatewayUrl: 'https://mcp-shield-gateway-core.vercel.app/v1/mcp',
  apiKey: process.env.MCP_SHIELD_KEY
});

const result = await shield.executeTool('database_query', { query: 'SELECT * FROM inventory' });
console.log('Attested Trace ID:', result.traceId);

Direct HTTP JSON-RPC 2.0 request:

curl -X POST https://mcp-shield-gateway-core.vercel.app/v1/mcp \
  -H "Authorization: Bearer mcp_live_sec_your_key" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"sql_read","arguments":{"query":"SELECT * FROM organizations"}}}'

FAQ

Frequently Asked Questions

Does MCP Shield add noticeable latency to LLM tool calls? +
No. MCP Shield uses an in-process, zero-copy evaluation engine written in high-efficiency Node.js. P99 latency overhead is consistently under 1.5ms, which represents less than 0.1% of typical LLM generation latency.
Do you store raw prompts or confidential database payloads? +
No. All tool inputs and responses are evaluated in volatile memory and immediately discarded. Only anonymized telemetry metadata (latency, tool identifier, status code, and SHA-256 hashes) is recorded in your Supabase audit log.
How does Ed25519 cryptographic signing work? +
Every tool execution approved by the gateway is digitally signed using an Ed25519 enclave key. This produces a lightweight cryptographic receipt that can be independently verified for SOC 2 Type II and HIPAA compliance audits.
Can I run MCP Shield locally on my machine? +
Yes. The npx mcp-shield wrap command runs directly on your local machine, intercepting stdio tool calls between Claude Desktop or Cursor and your local MCP servers without transmitting any database credentials to the cloud.
