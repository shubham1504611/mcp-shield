FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

Does MCP Shield add noticeable latency to agent tool calls? +
No. MCP Shield is engineered with a zero-copy, in-memory AST engine written in pure Node.js/Rust. P99 latency overhead is strictly under 1.5ms, which is completely imperceptible to LLMs.
Do you store our confidential data or prompts? +
No. MCP Shield operates statelessly. Raw tool payloads are evaluated in-memory and discarded. Only anonymized metadata (status code, latency, tool name, and cryptographic SHA-256 hashes) is written to your Supabase audit log.
How does Ed25519 cryptographic attestation help with compliance? +
Every tool execution is signed by an isolated enclave key. This creates an unbroken, tamper-evident cryptographic chain of custody required for SOC 2 Type II, ISO 27001, and HIPAA AI compliance audits.
Can I use MCP Shield locally in Claude Desktop or Cursor? +
Yes! You can run npx mcp-shield wrap to intercept local stdio tool calls on your laptop, or route through our cloud gateway (https://mcp-shield-gateway-core.vercel.app/v1/mcp).
