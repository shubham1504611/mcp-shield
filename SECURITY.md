# Security Policy 🛡️

The MCP Shield team takes the security of autonomous agent architectures and tool execution extremely seriously. We appreciate the responsible disclosure of any vulnerabilities found in MCP Shield or its associated packages.

---

## Supported Versions

| Package | Version | Supported |
| :--- | :--- | :---: |
| `@mcp-shield/gateway-core` | `>= 1.0.0` | ✅ |
| `mcp-shield` (CLI) | `>= 1.0.0` | ✅ |
| `@mcp-shield/database` | `>= 1.0.0` | ✅ |
| `@mcp-shield/web-dashboard` | `>= 1.0.0` | ✅ |

---

## Reporting a Vulnerability

**Please DO NOT report security vulnerabilities through public GitHub issues.**

If you believe you have found a security vulnerability in MCP Shield, please report it privately:

1. **Email**: Send detailed reproduction steps, exploit payloads, and environment details to **`security@mcpshield.dev`**.
2. **PGP / Encrypted Communication**: Available upon request.
3. **Response Time**: You will receive an initial response from our security team within **24 hours**.

---

## What to Include in Your Report

* Clear description of the vulnerability (e.g. AST filter bypass, timing side-channel, prompt injection bypass).
* Step-by-step instructions to reproduce the issue.
* A minimal Proof of Concept (PoC) script or raw JSON-RPC frame.
* Suggested fix or remediation if known.

---

## Responsible Disclosure & Bounty

We follow standard responsible disclosure practices. Once a vulnerability is verified, we will work promptly to deploy a patch before public disclosure.
